# HelioGrid Solar Agency Website

Modern 3D solar panel agency landing page with:

- Hero section
- About us section
- Services section
- Contact lead generation form
- Admin panel with lead metrics, pipeline tracking, search, status updates, delete, demo data, and CSV export

## Run

Open `index.html` in a browser, or serve the folder with any static server.

Lead data is saved in the browser using `localStorage`.
